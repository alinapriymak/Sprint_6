# Автотесты для «Яндекс.Самокат»

UI-автотесты для сервиса «Яндекс.Самокат». 

Тесты написаны с использованием **Selenium**, **Page Object Model**, **параметризации** и **Allure-отчёта**.

---

## 📁 Структура проекта
```
Sprint_6/
├── pages/ # Page Object классы
│ ├── init.py
│ ├── base_page.py # Базовый класс с общими методами
│ ├── home_page.py # Главная страница
│ └── order_page.py # Страница заказа
```

## 🚀 Установка и запуск

### 1. Клонирование репозитория

```bash
git clone <repository-url>
cd Sprint_6
```


### 2. Установка зависимостей

```
pip install -r requirements.txt
```

### 3. Запуск тестов

Запуск тестов с Allure-отчётом:
```
pytest tests/ --alluredir=allure_results
```

Просмотр Allure-отчёта:
```
allure serve allure_results
```

## Тестовые сценарии

### 1. Выпадающий список «Вопросы о важном» (FAQ)
**Сценарий**: Проверка, что при нажатии на стрелочку открывается соответствующий текст.

8 параметризованных тестов (по одному на каждый вопрос)

Тест проверяет соответствие текста ответа ожидаемому

**Файл**: tests/test_faq_accordion.py


### 2. Заказ самоката
**Сценарий**: Позитивный сценарий заказа с двумя наборами данных и двумя точками входа.

**Точки входа**:

Кнопка «Заказать» в хедере сайта

Кнопка «Заказать» в блоке Как это работает

**Файл**: tests/test_order.py


### 3. Редиректы по логотипам
**Сценарий 1**: Клик на логотип «Самоката» — переход на главную страницу

**Сценарий 2**: Клик на логотип Яндекса — открытие главной страницы Дзена в новой вкладке

**Файл**: tests/test_logo_redirect.py


### Браузер
По умолчанию тесты запускаются в Firefox. Для изменения браузера отредактируйте conftest.py.
